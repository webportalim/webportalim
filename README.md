## Featured projects

### 🎬 [MotionSmith AI Animation Studio — Unreal Engine](https://github.com/webportalim/MotionSmith-Kimodo-Animation-Studio)

An AI-assisted character animation authoring plugin for **Unreal Engine 5.8 (Windows)**. Generate motion from text, extend animations with timeline segments, edit poses, retarget to supported character rigs, and export Unreal AnimationSequences.

[**Free Fab listing**](https://www.fab.com/listings/21c531e5-02b0-4d4a-960d-8cceab5dba34) · [Repository](https://github.com/webportalim/MotionSmith-Kimodo-Animation-Studio) · [Documentation](https://motionsmithai.blogspot.com/p/docs.html)

### 🎨 [MotionSmith Surface — Blender](https://github.com/webportalim/MotionSmith-Surface)

**AI texture generation and PBR material creation** inside Blender, backed by a local ComfyUI setup. Supports image- and prompt-guided texturing, multi-view workflows, UV baking, and PBR map generation.

[**Repository & installation**](https://github.com/webportalim/MotionSmith-Surface) · [Surface documentation](https://motionsmithai.blogspot.com/p/motionsmith-surface-docs.html) · [Product page](https://motionsmithai.blogspot.com/p/motionsmith-surface.html)
